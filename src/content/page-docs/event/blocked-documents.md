## À quoi sert cet écran

Cette adresse n'affiche pas d'écran propre : les documents bloqués sont gérés dans l'écran **Listes de blocage**, onglet **Documents**. Vous y êtes redirigé automatiquement (vers l'écran Listes de blocage, ouvert sur l'onglet **E-mails** : cliquez sur **Documents** pour accéder à la liste des pièces bloquées).

Voir la documentation de l'écran **Listes de blocage** pour le détail.
