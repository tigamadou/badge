# Badges

## Acceder aux badges

Cliquer sur "Badges" dans le menu. La page affiche une grille de cartes representant toutes les inscriptions approuvees.

Chaque carte montre :
- Photo du participant (ou initiales)
- Nom et structure
- Categorie
- Mention "ALL ACCESS" si active
- Statut d'impression (Imprime / Non imprime)

En haut de la page, des compteurs affichent le total des badges, le nombre d'imprimes et de non imprimes.

## Rechercher et filtrer

- **Recherche** : par nom, email ou structure
- **Filtre par categorie** : selectionner une categorie
- **Filtre par impression** : Tous / Imprimes / Non imprimes

## Consulter un badge

1. Cliquer sur une carte dans la grille
2. La page de detail s'ouvre avec deux zones :
   - A gauche : informations du participant et boutons d'action
   - A droite : apercu du badge PDF en temps reel

Le badge affiche :
- Logo et informations de l'evenement (haut)
- Photo du participant et QR code (centre)
- Identifiant du badge (vertical, a droite)
- Nom et structure
- Banniere "ALL ACCESS" en rouge (si active)
- Banniere de la categorie en couleur (bas)

## Activer l'acces total (ALL ACCESS)

Cette option ajoute une banniere rouge "ALL ACCESS" sur le badge.

1. Ouvrir la page de detail d'un badge
2. Le bouton "ALL ACCESS" est disponible si le badge est approuve et non encore imprime
3. Cliquer sur le bouton
4. Confirmer l'activation dans la fenetre de confirmation
5. L'apercu du badge se met a jour immediatement

## Marquer un badge comme imprime

Prerequis : les informations de contact (email et telephone) doivent etre configurees dans les parametres systeme. Si ce n'est pas le cas, un message d'avertissement s'affiche.

1. Ouvrir la page de detail d'un badge
2. Cliquer sur "Marquer comme imprime"
3. Confirmer dans la fenetre de confirmation
4. Le badge est marque comme imprime avec la date
5. Un email est envoye au participant avec les informations pour recuperer son badge

Une fois marque comme imprime, le badge ne peut plus etre modifie (ALL ACCESS fige).

## Telecharger un badge en PDF

1. Ouvrir la page de detail d'un badge
2. Cliquer sur le bouton de telechargement
3. Le fichier PDF est telecharge sous le nom `badge-NOM-PRENOM-ID.pdf`

Le PDF est au format 100 x 140 mm, pret pour l'impression.
