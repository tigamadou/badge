# Tableau de bord

Le tableau de bord est la premiere page affichee apres la connexion. Il presente une vue d'ensemble de l'activite sous forme d'indicateurs chiffres.

## Indicateurs affiches

### Inscriptions

- **Total** : nombre total d'inscriptions dans le systeme
- **En attente** : inscriptions avec le statut "En attente" (PENDING)
- **Approuvees** : inscriptions approuvees (APPROVED)
- **Rejetees** : inscriptions rejetees (REJECTED)

### Badges

- **Imprimes** : nombre de badges marques comme imprimes
- **Non imprimes** : nombre de badges non encore imprimes (parmi les inscriptions approuvees)
- **ALL ACCESS** : nombre de badges avec l'acces total active

### Scans

- **Total** : nombre total de scans effectues
- **Aujourd'hui** : nombre de scans effectues ce jour
- **Participants uniques** : nombre de participants differents scannes

### Utilisateurs (visible pour les administrateurs et super administrateurs)

- **Total** : nombre total de comptes utilisateurs
- **Administrateurs** : nombre d'administrateurs
- **Operateurs** : nombre d'operateurs

## Navigation

La barre laterale (sur ordinateur) ou le menu hamburger (sur mobile) permet d'acceder a toutes les sections de l'application. Les elements du menu varient selon votre role.
