# Journal d'activite

Acces reserve aux administrateurs et super administrateurs.

## Acceder au journal

Cliquer sur "Journal d'activite" dans le menu lateral.

## Consulter les logs

Le journal affiche toutes les actions effectuees dans l'application, des plus recentes aux plus anciennes :
- Date et heure de l'action
- Type d'action (avec un badge colore par famille)
- Utilisateur qui a effectue l'action
- Description contextuelle
- Identifiant de la ressource concernee

### Familles d'actions

| Couleur | Famille | Exemples |
|---------|---------|----------|
| Vert | Inscriptions | Inscription creee, approuvee, rejetee, supprimee |
| Violet | Badges | Badge imprime, ALL ACCESS modifie, badge exporte |
| Bleu | Scans | Badge scanne |
| Orange | Utilisateurs | Utilisateur cree, modifie, supprime, connexion |
| Gris | Configuration | Categorie modifiee, evenement modifie, parametres modifies |

## Filtrer les logs

- **Par type** : selectionner une famille (Inscriptions, Badges, Scans, Utilisateurs, Configuration) dans le menu deroulant
- **Par utilisateur** : selectionner un utilisateur dans le menu deroulant
- **Par recherche** : saisir un texte pour rechercher dans les descriptions (nom de participant, structure, etc.)
- **Par dates** : definir une date de debut et/ou de fin

## Pagination

La liste est paginee (30 entrees par page). Utiliser les boutons Precedent / Suivant pour naviguer.
