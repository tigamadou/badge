# Utilisateurs

Acces reserve au super administrateur.

## Consulter la liste des utilisateurs

1. Acceder a la section "Utilisateurs" via le menu
2. La liste affiche pour chaque utilisateur : nom, email, role
3. Utiliser le filtre par role pour affiner l'affichage

## Inviter un nouvel utilisateur

1. Cliquer sur le bouton "Nouvel utilisateur"
2. Remplir le formulaire :
   - **Nom** : nom complet de l'utilisateur
   - **Email** : adresse email (servira d'identifiant de connexion)
   - **Role** : Operateur, Administrateur ou Super Administrateur
3. Valider

Un email d'invitation est automatiquement envoye a l'adresse indiquee. Cet email contient un lien securise valable 48 heures permettant a l'utilisateur de definir son mot de passe.

## Modifier un utilisateur

1. Cliquer sur le bouton de modification sur la ligne de l'utilisateur
2. Modifier les champs souhaites :
   - Nom
   - Email
   - Role
   - Mot de passe (optionnel, pour reinitialiser)
3. Valider

## Supprimer un utilisateur

1. Cliquer sur le bouton de suppression sur la ligne de l'utilisateur
2. Confirmer dans la fenetre de confirmation

Il est impossible de supprimer votre propre compte. La suppression est definitive.

## Roles disponibles

| Role | Description |
|------|-------------|
| Operateur | Consultation des inscriptions, gestion des badges, scan QR |
| Administrateur | + gestion des categories, de l'evenement et des parametres |
| Super Administrateur | + gestion des comptes utilisateurs |
