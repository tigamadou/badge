# Guide utilisateur

Ce guide est destine aux operateurs et administrateurs qui utilisent l'application Investiture au quotidien.

## Roles et permissions

L'application definit trois roles avec des niveaux d'acces croissants :

**Operateur**
- Tableau de bord
- Consulter et gerer les inscriptions
- Consulter et gerer les badges
- Scanner les QR codes des badges
- Gerer son profil

**Administrateur** (tout ce que peut faire un operateur, plus :)
- Gerer les categories de participants
- Configurer l'evenement
- Gerer les parametres systeme (SMTP, contact)
- Consulter le journal d'activite

**Super Administrateur** (tout ce que peut faire un administrateur, plus :)
- Gerer les comptes utilisateurs (creation, modification, suppression)
