# Inscriptions

## Consulter la liste

1. Acceder a la section "Inscriptions" via le menu
2. La liste affiche toutes les inscriptions avec : nom, email, structure, categorie, statut, date

### Rechercher

Utiliser la barre de recherche en haut de la liste pour filtrer par nom, email ou structure.

### Filtrer

- **Par statut** : selectionner "En attente", "Approuve" ou "Rejete" dans le menu deroulant
- **Par categorie** : selectionner une categorie dans le menu deroulant

## Approuver ou rejeter une inscription

### Depuis la liste (action rapide)

Pour les inscriptions en attente, deux boutons d'action sont disponibles directement sur chaque ligne :
1. Cliquer sur le bouton vert pour approuver
2. Cliquer sur le bouton rouge pour rejeter

### Depuis la page de detail

1. Cliquer sur une inscription pour ouvrir sa page de detail
2. Consulter les informations completes, la photo et le document d'identite
3. Cliquer sur "Approuver" ou "Rejeter"

Dans les deux cas, un email de notification est automatiquement envoye au participant pour l'informer de la decision.

## Voir le detail d'une inscription

1. Cliquer sur une inscription dans la liste
2. La page de detail affiche :
   - Photo du participant (ou initiales si pas de photo)
   - Nom, prenom, email, structure
   - Categorie avec indicateur de couleur
   - Type et numero de piece d'identite
   - Document d'identite (cliquer dessus pour l'agrandir)
   - Date de creation
   - Statut actuel
3. Si l'inscription est approuvee, un lien vers la page badge est disponible

## Creer une inscription manuellement

1. Cliquer sur le bouton "Nouvelle inscription"
2. Remplir le formulaire :
   - Nom, prenom, email, structure
   - Categorie
   - Type et numero de piece d'identite
   - Photo du participant
   - Document d'identite
3. Valider le formulaire
4. L'inscription est creee avec le statut "En attente"

## Supprimer une inscription

1. Ouvrir la page de detail de l'inscription
2. Cliquer sur le bouton de suppression
3. Confirmer la suppression

La suppression est definitive.
